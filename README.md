## Visão geral da linguagem e da plataforma .NET

C# é uma linguagem lançada oficialmente em fevereiro de 2002, juntamente com a plataforma .NET 1.0 da Microsoft, à qual está intrinsecamente ligada. C# requer este ambiente de execução para funcionar, o qual fornece um conjunto muito amplo de classes.

À primeira vista, a plataforma .NET é um ambiente de execução semelhante a uma máquina virtual Java, com algumas diferenças notáveis:

**Multiplataforma**: enquanto o Java tem sido executado em diversos sistemas operativos desde o seu início, o .NET limitava-se inicialmente ao Windows. No entanto, o projeto **[Mono](http://www.mono-project.com)** permite agora utilizar o .NET em sistemas como o Unix e o Linux.


**Multilíngue**: A plataforma .NET permite executar programas escritos em diferentes linguagens, desde que o seu compilador gere código IL (linguagem intermédia). Todas as classes do .NET estão disponíveis para estas linguagens, o que tende a esbater as diferenças entre elas; escolher uma linguagem .NET torna-se, assim, uma questão de preferência mais do que de desempenho.





## Evolução da linguagem

Em 2002 (C# 1.0), a linguagem era muito semelhante ao Java, o que facilitava a transição de um ambiente para outro. Desde então, as características específicas de cada linguagem tornaram-se mais diferenciadas.

Com a chegada do C# 3.0 e do framework .NET 3.5, surgiram inúmeras novas características, das quais a mais significativa é provavelmente o **LINQ** (Language INtegrated Query). O LINQ permite consultar matrizes, listas, bases de dados ou ficheiros XML de forma uniforme (semelhante ao SQL).

>
